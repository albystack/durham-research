Initially, I was studying either the variance of one central height or the double dimer height difference. I think that, technically, the double dimer difference was not the quantity in which the existing random dimer paper predicts the squared-logarithmic contribution. 

I did scribble some maths (and also learnt some, too). If w denotes the Gamma environment, and H denotes the height observable, the total variance decomposes as 

Var(H) = E_w[Var(H|w)] + Var_w(E[H | w]) 

For two conditionally independent tilings H_1, and H_2, sampled using the same environment, then 

1/2 * Var(H_1 - H_2) = E_w[Var(H|w)], where as 

Cov(H_1, H_2) = Var_w(E[H|w]). 

I found this distinction clear in the numerical random dimer work of Zeng, Leath, and Haw, and also in the later super roughness work of Perret, Ristovjevic (I think), Le Doussal, and a few more writers. They distinguish the connected or conditional fluctuations, which grow logarithmically, from the disorder-induced background fluctuations, where the (logL)^2 term is predicted. 

From the Duits-Van Peski paper, their gamma reduction and polymer results provide the model and the structures we are using in our own experiment, although I did not find anything in the paper that proves the height fluctuation (they said it was undiscoverable I believe). 

The reason I realised our observable might be wrong was the double dimer experiment continued to give roughly logarithmic behaviour. I was like, what? The fitted exponent for the height difference was around 0.81, while the covariance between the two shared environment heights showed a stronger upwards curvature! In the earlier centre height data, its effective exponent was approximately 186!! When fitting from L >= 96 moving towards two at higher cutoffs, although with some uncertainty (not enough samples, I would need more computational power, or perhaps optimise my code). 

Reading the papers also explained this patter, the double difference isolates this connected component, which is EXPECTED to be logarithmic, while the more shared environment covariance isolates the disorder contribution, where the squared logarithm should occur. So, the early computation was not technically wasted, it separated the two components and led us to the correct observable we were looking for! 

I therefore implemented a new spatial height experiment, since the super roughness predictions in the papers usually stated for spatial height difference rather than solely for the height of one central face. 

For each gamma environment, I generated two conditionally independent tilings and measured symmetric central row increments (this will really stretch my latex skills): 

/delta H_/alpha ( r) = H_alpha ( x + r) - H_a (x), where alpha = 1,2, at separations 

R = L/32, L /16, L/8, L/4 

The primary quantities where T(r) = 1/2 Var(delta H_1 (r) - delta H_2 (r)) and also D(r) = Cov(delta H_1(r), delta H_2(r)). 

Where T(r) estimates the tiling distribution and D(r) estimates the disorder induced contribution. 

The final gamma dataset contains 6900 independent environments, with two tilings per invornments, 

L = 128, 192, 256, 384, 512, 700, 900, 1100, 1300 

I also generated 5500 independent uniform control pairs using the same observables. The purpose of it was to check the fitting method did not automatically manufacture this squared log curve which was expected to have ordinary log fluctuations. 

For the main analysis, I compared 

D(r) = a + b log r 

Against 

D(r) = a + blog(r) + c(log r) ^ 2. 

With a and b having subscript \rho. 

Each relative separation \rho was allowed its own intercept and ordinary log slope, but the four separations shared one common squared log coefficient c. Thanks for the email.  I think the next step is then to get height function and then compute the height in the center of the Aztec diamond for different realization.  The heights are defined on the faces of the graph (where the graph is the one with dimers as opposed to dominoes). 

The height function in this case is equal to +/-3 if you cross a dimer between a shared edge and -/+1 if do not cross a dimer between the shared edge. Here the sign depends on the parity, that is, if you go between two adjacent faces, the white vertex can be on either the left or the right and the sign is different for each case.  The construction is such if you go around each white vertex clockwise, the height function increases by 1 each time, unless you cross a dimer where the height function drops by 3. For black vertices, the convention is the opposite.  

Here is the Julia code for getting the height function:
#
function heightfunction(x0)
      n=size(x0)[1]
      m=Int(floor(n/2))
      A=zeros(n+1,m+1)
      for j in 1:m+1
            A[1,j]=2*j-2
      end
      for i in 2:n+1
            for j in 1:m
                  if Int(x0[i-1,2*j-1])==1
                        A[i,j]=A[i-1,j]+3
                  else
                        A[i,j]=A[i-1,j]-1
                  end
            end
      end
      return A
end

In the current Julia implementation, for the disordered cases I do not generate a fresh background for every individual loop-erased random walk. Instead, I generate several walks within each fixed environment, and then average over many independent environments. So the same environment is reused within each environment block, but not across different blocks.

The annealed variance I reported is computed from the pooled walks across all environments, with the uncertainty estimated using an environment-clustered bootstrap to account for the fact that walks from the same environment are correlated.

So if by “annealed” we mean a completely fresh background for every walk, then the present runs are not annealed in that strict sense. They are closer to a multi-walk-per-environment sampling scheme with averaging over independent environments.
