# Archived experiments

This directory contains self-contained historical experiments that are not
part of the active Julia package.

- [`random_walk/`](random_walk/) contains the earlier loop-erased-random-walk
  simulations, tests, compact results, and its original documentation.
- `previous_aztec_result_26050/` preserves the raster plot from the earlier
  26,050-sample Aztec analysis. The active, updated figure is an SVG under
  `aztec/results/height/`.
- [`hpc_recovery_202608/`](hpc_recovery_202608/) preserves the one-off packed
  Slurm recovery procedure used for the August 2026 campaigns.

The archive is retained for scientific provenance. New development should use
the package under `../aztec/`.
