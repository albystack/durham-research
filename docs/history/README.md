# Historical research records

These dated reports preserve the development of the model, sampling corrections,
feasibility checks and earlier campaigns. Their statements about pending jobs or
next steps describe the date of the report, not the current status.

Start with [the completed results](../RESULTS.md) and [current methods](../METHODS.md).
The [research handbook](../research/handbook.typ) connects the earlier stages.

Old large datasets and manuscript material were already archived locally and
in earlier Git revisions. They are excluded from the current checkout to keep
the public repository small. Older references to `archive/`, `docs/validation/`
and private correspondence describe that historical local workspace. The public
latest data and verification provenance are under [data/](../../data/README.md).
