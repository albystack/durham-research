## Project Aim

The project should focus on **Extension 3** from the email discussion: simulate loop-erased random walks in a fixed site-dependent random environment and measure how the winding variance of the path from the centre to the boundary scales with box size.

The central question is:

> Does the winding variance grow like `C log L`, as in the symmetric UST/LERW case, or like `C(log L)^2` in the fixed random-environment case?

Here `L` is the box size and the winding is measured as:

```text
number of left turns - number of right turns
```

## Confirmed Modelling Choice

Use a **fixed-in-time site-dependent environment**.

At each site, assign outgoing edge weights:

```text
N weight = 1
E weight = 1
S weight = u
W weight = v
```

where `u` and `v` are sampled from a positive distribution with mean `1`.

The corresponding transition probabilities are:

```text
p_N = 1 / (2 + u + v)
p_E = 1 / (2 + u + v)
p_S = u / (2 + u + v)
p_W = v / (2 + u + v)
```

This avoids negative probabilities and follows Prof. Chhita's latest guidance in `outlook.txt`.

Recommended starting distributions:

- Exponential distribution with mean `1`
- Gamma distribution with mean `1`
- Several Gamma shape parameters to control disorder strength

## Main Research Questions

1. What is the known winding variance result for ordinary symmetric LERW/UST?
2. What theoretical or numerical evidence exists for winding variance in random environments?
3. Does a fixed mean-one random environment produce stronger winding fluctuations than the symmetric case?
4. Is the observed scaling closer to `C log L` or `C(log L)^2`?
5. How does the disorder strength affect the scaling?
6. Can the variance be decomposed into within-environment and between-environment contributions?
7. What simulation sizes and sample counts are needed before the evidence becomes meaningful?

## Simulation Plan

### Stage 1: Reproduce the Symmetric Baseline

Goal: confirm that the existing code reproduces the known symmetric behaviour.

Tasks:

- Run LERW from the centre to the boundary with transition probabilities `1/4`.
- Compute winding for many samples.
- Estimate variance for several box sizes.
- Plot variance against `log L`.
- Check that the result is broadly consistent with `C log L`.

Suggested initial sizes:

```text
L = 16, 32, 64, 128
```

### Stage 2: Implement the Fixed Random Environment

Goal: implement Prof. Chhita's edge-weight model.

Tasks:

- For each site, sample `u` and `v` once.
- Convert edge weights into transition probabilities.
- Keep the environment fixed throughout each walk.
- Run the random walk from the origin until it hits the boundary.
- Loop-erase the path.
- Compute winding.

Important: for this model, describe the object as **LERW in a random environment** or a **weighted random-walk spanning tree model**, not simply as the ordinary UST.

### Stage 3: Disorder Parameter Sweep

Goal: test how disorder strength affects winding variance.

Suggested Gamma distribution:

```text
u, v ~ Gamma(shape = k, scale = 1/k)
```

This gives:

```text
E[u] = E[v] = 1
Var(u) = Var(v) = 1/k
```

Suggested values:

```text
k = 20, 10, 5, 2, 1, 0.5
```

Large `k` means weak disorder. Small `k` means strong disorder.

### Stage 4: Scaling Analysis

For each disorder level and box size:

- Estimate mean winding.
- Estimate variance of winding.
- Plot variance against `log L`.
- Plot variance against `(log L)^2`.
- Fit both models:

```text
Var(W_L) = a log L + b
Var(W_L) = a (log L)^2 + b
```

Compare:

- visual linearity
- residuals
- confidence intervals
- stability when small `L` values are removed

### Stage 5: Variance Decomposition

If computationally feasible, run multiple walks inside each frozen environment.

Use:

```text
Var(W) = E[Var(W | environment)] + Var(E[W | environment])
```

This separates:

- within-environment randomness
- between-environment randomness

This is useful because any possible `(log L)^2` effect may be driven by differences between frozen environments.

## Risks And Pitfalls

- Small box sizes may not distinguish `log L` from `(log L)^2`.
- Strong disorder may cause very long walks or unstable runtimes.
- The Gamma distribution must be parametrised carefully so the mean is exactly `1`.
- The environment must be fixed during a walk; resampling at every step would answer a different question.
- The boundary convention must remain consistent across all simulations.
- Mean-one weights balance the raw edge-weight scale, but normalisation can still create an effective transition-probability drift. Record boundary hit locations and raw walk lengths as diagnostics.
- Large sample sizes are likely needed before conclusions are credible.
